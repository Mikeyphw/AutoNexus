# Final consolidated feature specifications

All four documents below are user-approved scope specifications and remain **roadmaps**, not claims that features work in the bootstrap:

- `roadmaps/AutoNotification.md` — HTML restoration, full Notify/Intercept/Query/Channels/Tiles UI/UX, optional scoped SystemUI, root diagnostics.
- `roadmaps/AutoInput.md` — Actions v2, UI Query, gesture/screenshot/editor UX, optional root input and SystemUI state.
- `roadmaps/AutoTools.md` — all 33 configuration activities, JSON Read/Write Studio, Web Screens, Dialogs, Secure Settings, optional root verification.
- `roadmaps/TermuxTasker.md` — confirmed symptom: Tasker says existing plugin action did not respond, especially after reboot; two-sided IPC trace; entire editor overhaul; no SystemUI.

Implementation delivery shall be consolidated per domain, not serial chains of cosmetic corrective overlays. Every proposed behavior-changing feature needs runtime compatibility and device acceptance, and all validations must distinguish local, hosted, physical and release evidence.
